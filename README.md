# 刻度｜专注计划助手

刻度是一款**本地优先、离线可用**的个人专注计划工具，把任务计划、日历、番茄钟、每日复盘、睡眠打卡和统计放在同一个应用里。数据默认只保存在你自己的设备（浏览器 IndexedDB）中，不依赖账号，也不会上传到任何公共服务器。

应用以 Vite + React + TypeScript 构建，是响应式 PWA 网页应用：手机端使用底部导航，PC 端使用顶部导航，可安装到 Android 主屏幕或 Windows 桌面。

## 功能

### 今日

- 今日进度：当天任务完成数、已专注时长。
- 时间轨道：把当天每次专注按真实时段绘制在 07:00–22:00 的时间轴上。
- 今日任务快捷列表与完成率等指标。

### 任务

- 新建、查看详情、编辑、完成、删除任务（删除采用软删除，保留墓碑记录）。
- 字段：标题、说明、计划日期、截止日期、优先级（高/中/低）、分类、预计番茄数。
- 按关键词搜索，按“待完成 / 已完成 / 全部”筛选；任务按优先级排列，同优先级下最早创建的在前。
- 支持每天、每周同一天或指定星期重复；完成当前任务时只生成下一次，避免未来任务堆积。
- 分类支持自定义名称与颜色，可停用；停用分类不影响历史统计。

### 日历

- 月视图：每格展示当天任务数量，有专注记录时显示标记。
- 点击任意日期查看当天任务，并直接填写当日复盘。
- 已填写复盘的日期会显示独立标记。

### 番茄钟

- 专注、短休息、长休息三种阶段；专注/短休息/长休息时长和长休息间隔可在设置中调整。
- 环形进度显示，支持暂停、继续、提前结束并记录、重置；达到目标时长后进入正向超时计时，直到手动结束。
- 开始前可关联一个未完成任务；完成或提前结束时生成一条专注记录（开始/结束时间、实际秒数与分钟数、关联任务与分类）。
- 今日专注记录列表，可删除记录。

### 复盘

- 每日复盘：今日收获、可以改进、明日计划，按日期浏览历史；手机端点击字段进入沉浸式长文编辑。
- 一键导出当日复盘为 Markdown（含当天完成任务数与专注时长）。
- 支持全文搜索历史复盘，自动生成周/月任务、专注、睡眠与文字汇总，并导出周期 Markdown。

### 睡眠

- 按起床日期打卡，分别记录入睡/起床的日期与时间，支持跨午夜计算。
- 主观睡眠评分（1–5 分）。
- 统计页展示平均时长、平均入睡/起床时间、平均评分、趋势与 24 小时睡眠覆盖。

### 统计

- 周、月、年、自定义日期范围，支持前后翻页。
- 累计专注时长与次数、有记录天数、日均专注时长（“有记录日”或“周期自然日”两种口径）。
- 按分类的专注时长占比、每日/每月专注趋势、24 小时专注时段分布。
- 无数据时显示引导，不展示空图表。
- 统计按北京时间（UTC+8）计算；跨小时/跨午夜的专注按实际时间分摊到各时段与自然日。

### 设置

- 主题：浅色、深色、跟随系统。
- 计时偏好：专注/短休息/长休息时长、长休息间隔。
- 分类管理：新增、改名、改色、停用/启用。
- 数据管理：JSON 备份导入导出、CSV 导出、清空所有数据。
- 同步：可连接个人 WebDAV；仓库同时提供只在个人局域网运行的 WSL HTTPS 同步服务。
- 云端恢复：个人同步服务会保留最近 50 个历史版本，可在设置中比较差异、下载 JSON、安全合并或恢复本机。
- PWA：安装应用、申请浏览器持久存储，并可在设置页主动检查和应用更新。

## 数据与隐私

- **本地优先**：全部数据写入浏览器 IndexedDB，刷新或关闭页面不丢失。
- **离线可用**：断网时仍可创建任务、计时、复盘和查看统计。
- **备份可控**：设置页可离线导出带格式版本号的 JSON 备份；手机优先调用系统保存或文件分享，并保留浏览器下载回退。导入前先预览，可选择“覆盖”（需二次确认，并先保存导入前备份）或“合并”（按记录 ID 对齐，内容不同的同 ID 记录逐条选择保留本地或使用导入）。
- **CSV 导出**：任务、专注记录、睡眠记录可导出为 UTF-8 BOM 的 CSV，可直接用 Excel 打开。
- 清除浏览器站点数据会删除全部记录，请定期导出 JSON 备份。
- WebDAV 是可选的手动同步：地址、用户名和密码只保存在当前浏览器，不会写入 JSON 备份。远端内容不同时必须手动选择版本，拉取前会先导出本机备份。
- 仓库内置的局域网同步服务器运行于个人 WSL，数据只写入指定本机目录，不要求公共云，也不应配置路由器公网端口转发。
- GitHub Pages 是 HTTPS 页面，因此局域网同步服务器同样使用 HTTPS，并显式允许刻度页面跨域访问。

## 技术栈

- 构建：Vite + TypeScript
- UI：React、React Router、date-fns、lucide-react
- 图表：Recharts
- PWA：vite-plugin-pwa（Workbox，Service Worker 更新由用户确认，避免打断计时）
- 存储：IndexedDB（仓库抽象支持内存实现，便于测试）
- 可选局域网服务：Python 3.12 标准库 + WSL 2，无第三方运行依赖
- 测试：Vitest + Testing Library + jsdom
- 代码规范：ESLint（typescript-eslint）

## 快速开始

环境要求：Node.js 20+（GitHub Actions 中使用 Node 24）。

```bash
npm install
npm run dev
```

常用命令：

```bash
npm run dev        # 本地开发
npm run build      # 类型检查并构建到 dist/
npm run preview    # 本地预览构建产物
npm run lint       # ESLint 检查
npm run test       # 运行测试（-- --run 为单次执行）

# 在 WSL 中测试可选的局域网同步服务器
cd sync-server
python3 -m unittest -v test_server.py
```

## 目录结构

```text
src/
├── App.tsx                   # 页面路由与主要组件（今日/任务/日历/计时/复盘/睡眠/设置）
├── main.tsx                  # 应用入口
├── styles.css                # 全部样式（响应式 + 明暗主题）
├── components/
│   ├── DataManagement.tsx    # JSON 备份导入导出、CSV 导出
│   └── WebDavSync.tsx        # WebDAV 配置、同步与版本冲突保护
├── data/
│   ├── repository.ts         # IndexedDB / 内存仓库
│   └── seed.ts               # 初始演示数据
├── domain/
│   ├── types.ts              # 领域类型（任务、专注、复盘、睡眠、计时器、设置）
│   └── selectors.ts          # 软删除过滤等选择器
├── pages/
│   └── StatsPage.tsx         # 统计页（懒加载）
├── pwa/                      # PWA 注册、安装提示、持久存储
├── state/
│   └── AppContext.tsx        # 全局状态、reducer、防抖自动保存、主题与计时器心跳
├── test/                     # 测试环境配置
└── utils/                    # 统计、睡眠、备份、CSV、复盘 Markdown 导出
sync-server/                  # 个人 WSL 局域网 HTTPS 同步服务、证书脚本与部署说明
```

核心数据模型见 `src/domain/types.ts`：任务、分类、专注记录、每日复盘、睡眠记录、计时器状态与应用设置。

## 部署

推送到 `main` 分支后，GitHub Actions（`.github/workflows/deploy-pages.yml`）会自动执行 lint、测试、构建并发布到 GitHub Pages。构建时使用仓库名作为路由与静态资源前缀，并生成 `404.html`，刷新 `/stats` 等子路径不会 404；若仓库名为 `用户名.github.io` 则自动使用根路径。

详细发布步骤见 `Github发布及更新.md`。

## Android App 开发

项目已接入 Capacitor Android 容器。Android 端复用现有 React 页面和本地数据，不依赖浏览器地址栏，也不会显示浏览器广告；原生容器默认使用沉浸式全屏。

常用命令：

    npm run android:sync          # 构建 Web 资源并同步到 Android 工程
    npm run android:open          # 用 Android Studio 打开工程
    npm run android:build:debug   # 构建可安装的 debug APK
    npm run android:build:release # 构建 release APK（需要签名配置）

Android 版本号由 package.json 同步到 android/app/build.gradle。首次构建前需要安装 Android SDK、Android Studio 和对应的 SDK Platform/Build Tools；当前项目已生成 android/ 工程，但本机尚未检测到 Android SDK，因此 APK 构建仍需在配置 Android 工具链后执行。
